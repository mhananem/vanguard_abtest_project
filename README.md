# Vanguard A/B Testing Analysis Project

# Project Overview
This project analyzes an A/B test conducted for Vanguard to evaluate whether a redesigned user experience (Test group) improves customer conversion compared to the existing experience (Control group).

The analysis includes
-Client Behavior Analysis
-KPI and Performance Metrics
-Hypotheis Testing
-Funnel Analysis
-Tableau Visualization

# Objective
To determine whether the new design:
  -Reduces user drop-off
  -Improves conversion rates
  -Performs consistently across customer segments.


# Analysis Performed
-Data cleaning performed for 4 different files such as demo,experiment and web data.
-Did Client behavior analysis to understand client and their distribution for various segments accross test and control.
-Did Hypothesis testing using statistical test to validate the findings.
-Checked performance of test and control version for various KPI's such as Conversion rate,Error rate, error rate per step and return rate.
-Did funnel analysis to understand performance of test and control for each process step.

# Tools Used
-Python
-Pandas
-Juptyr Notebook
-Tableau


# Key Findings
-Test and Control groups were reasonably balanced across customer profiles.
-The Test group achieved higher overall conversion.
-Largest improvement occurred at the initial funnel stage.
-Customer segments showed generally consistent improvement under the Test design.


# Conclusion
Completion Rate increased by +3.4pp 
→: Improvement does not meet the 5% cost-effectiveness threshold
→  Senior and elder clients had lower CR as compared to the other group

 Drop-off rate decreased  by -14pp for the overall funnel 
→ Less test users left the funnel before reaching Confirm step

: Error rate slightly increased by + 0.88pp 
→ Some users navigate with a bit of confusion
: Time per Step slightly decreased  by 1 min on average  
→ Test users spend less time on most steps

:  Return rate is marginal by 0.3pp for test users 
→ Some test users return on the platform more than once
→ The new design works best for young client  (under 48 yo)
